# ClinicDesk

Clinic appointment system with 3 roles: admin, doctor, patient.
PHP + MySQL, AdminLTE 3 for the UI. No framework.

GitHub: https://github.com/mohammadAlaydi/clinicdesk

## Setup
1. Put the folder inside htdocs (XAMPP).
2. Import `sql/clinicdesk_db.sql` from phpMyAdmin.
3. Set your MySQL user/password in `config/database.php`.
4. Open http://localhost/clinicdesk

AdminLTE 3 assets go in `public/assets/adminlte` (already in the zip; if you clone from GitHub, download AdminLTE 3 and put dist + plugins there).
